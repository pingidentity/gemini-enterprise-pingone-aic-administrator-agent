**Overview (listing description):**

The PingOne AIC Administrator Agent brings PingOne Advanced Identity Cloud
administration into Gemini Enterprise. Help-desk operators search users,
reset passwords, manage sessions and MFA devices, change group and role
memberships, manage direct assignments, and read audit events. Every
state-changing action gated behind an explicit confirmation step and recorded
in the conversation.

- Runs in the customer's own Google Cloud project (deployed from the
  companion deployment listing). Tenant credentials never leave the customer
  project
- A2A-compatible, renders interactive A2UI workspaces in Gemini Enterprise
- Google OAuth2 (cloud-platform scope) protects every agent call
- Per-operator Google consent; role-scoped access via the customer's IdP
  groups
